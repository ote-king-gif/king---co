# King & co. | Fresh Sourdough Delivery

A responsive landing page for King & Co., a sourdough bakery that delivers fresh bread every week. Built as part of my internship.

**Live site:** https://king-and-co.vercel.app

## Description

The page lets visitors see how the service works and choose a weekly bread box. It includes:

- A hero section with a call to action
- A three-step "From our oven to your table" image grid
- Three subscription plans (Solo, Household and Bakery table)
- A customer quote and an email sign-up section
- Social media links and a footer
- A layout that adapts to phones, tablets and desktops

## Built With

- HTML5
- CSS3 (Grid, Flexbox, media queries)
- Font Awesome icons
- Google Fonts (Bricolage Grotesque and DM Sans)
- Hosted on Vercel

## How to Run

1. Clone the repository:
   ```
   git clone https://github.com/ote-king-gif/king---co
   ```
2. Open the folder:
   ```
   cd king---co
   ```
3. Open `index.html` in your browser.
   Or, in VS Code, right-click `index.html` and choose **Open with Live Server**.

No installation or build step is needed.
